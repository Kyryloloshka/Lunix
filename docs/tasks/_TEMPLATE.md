# T-000 · Назва

## Навіщо (людською мовою)
Два-три речення: що відчуває гравець зараз, чому це погано для гри чи бізнесу, що зміниться.

## Що бачимо зараз
Конкретні симптоми: екран, кроки, що видно. Посилання на файли з номерами рядків.

## Що зробити
Нумерований скоуп. Якщо задача L — розбити на етапи, кожен етап окремо мерджиться.

## Критерії готовності
- [ ] Перевірювані пункти: що гравець бачить / що покрито тестом.
- [ ] `npm run ts:check`, `npm test`, web export smoke check пройшли.

## Поза скоупом
Що свідомо не робимо в цій задачі.

## Де в коді
Файли та слайси, які зачіпаються. Нагадування про FSD-межі, якщо доречно.

## Ризики і відкриті питання
Що треба вирішити людині, що може зламатись.
