# T-004 · Дизайн-система «Terminal Workbench» v1

## Навіщо (людською мовою)
**Бізнес-сенс є, і чималий:**
1. **Впізнаваність у сторі.** Клікерів тисячі; скріншоти «як твоя IDE о 2-й ночі» — це наш
   диференціатор із PRD. Зараз стиль уже правильний за духом (графіт, фосфор, моно), але не доведений:
   системний `monospace`, емодзі поруч із гліфами, різні розміри однакових речей.
2. **Швидкість контенту.** PRD планує 40+ скілів, 60+ апгрейдів, 200+ ачівок, інциденти, квести.
   Кожна нова сутність має збиратися з готових `Card`, `Meter`, `Button`, а не копіпастою стилів —
   інакше кожен епік повторює верстку і плодить розбіжності.
3. **Монетизація без пейволу.** E15 продає косметику «IDE-теми» (Dracula-подібні, Solarized-подібні
   пародії). Це можливо лише якщо *весь* UI читає кольори з семантичних токенів теми. Зараз кольори
   зашиті у віджетах — тему не продаси.
4. **Доступність = більше гравців.** Текст 8–9 px і стан лише кольором відсікають частину аудиторії й
   ризикують зауваженнями від рев'ю.

## Що бачимо зараз
- `shared/theme/tokens.ts` має два паралельні набори кольорів: нова палітра і «тимчасові аліаси»
  (`green/indigo/rose/gold`), які досі використовуються в `Badge`, `GameButton`.
- `shared/ui` має `GameButton`, `StatPlate`, `ResourcePill`, `SectionHeader` — **жоден не
  використовується**; віджети верстають власні кнопки (4 різні «Купити/Промоут/Тогл/Таб»).
- Сегментовані перемикачі зроблені 4 рази окремо: режими покупки, підвкладки скілів, мова, нотація.
- Прогрес-бари — 4 реалізації: стрес, комбо (HUD), `ProgressBar`, вимоги кар'єри.
- Розміри шрифтів у віджетах — магічні числа 8/9/10, поза шкалою `typography.sizes`.
- Ресурси не мають єдиної ідентичності: Influence і Flow обидва з гліфом `bolt`; у форматерах —
  емодзі `🧠`/`⚡` (`formatDecimal.ts:100-106`), хоча токени кажуть «no emoji-driven UI».
- `GameButton primary` — білий текст на `#9f91bc` (низький контраст).
- Заголовки то моно, то системний sans (`SettingsPanel.heading` vs `CareerRoadmap.title`).
- Мертві стилі `rank0..rank8` у `WorkspaceClicker.tsx` (тема рангу вже йде з `getRankTheme`).

## Що зробити

### Етап 1 — Токени (S–M, можна мерджити окремо)
1. Семантичні токени замість сирих: `surface.{base,raised,inset}`, `text.{primary,secondary,muted,onAccent}`,
   `border.*`, `feedback.{success,warning,danger}`, `focus`.
2. **Ідентичність ресурсів** як токени: `resource.capital|cognitive|influence|stress|flow` →
   `{ color, bg, glyph, label i18n key }`. Кожен ресурс має свій унікальний гліф (Influence ≠ Flow).
3. Видалити аліаси `green/indigo/rose/gold`, перевести споживачів.
4. Шкала типографіки з мінімумом **11 pt** для будь-якого читаного тексту, ролі: `display`, `title`,
   `body`, `label`, `mono-num` (табличні цифри для лічильників, щоб не «стрибали»).
5. Тема = об'єкт токенів; `getRankTheme` стає накладкою акценту поверх базової теми. Структура
   готова до `ThemeProvider` / зміни теми в рантаймі (база для E15).
6. Перевірка контрасту: тест, що пари text/surface у темі дають ≥ 4.5:1 (чиста функція на hex).

### Етап 2 — Компоненти (M)
`Button` (tones: primary/secondary/ghost/danger; стани: disabled з причиною, loading), `SegmentedControl`,
`Toggle`, `Meter` (стрес/комбо/прогрес, з текстовим значенням для a11y), `Card`/`ListRow`
(іконка + тіло + trailing action — для скілів, апгрейдів, рангів, лідерів), `PanelHeader`, `ResourceValue`.
Мінімальна ціль дотику 44 pt вбудована. Замінити всі ручні реалізації у віджетах; видалити невикористані
компоненти.

### Етап 3 — Бренд (S, needs-approval)
- Моноширинний шрифт з відкритою ліцензією (JetBrains Mono / IBM Plex Mono, OFL) через `expo-font`.
- Прибрати емодзі з форматерів — значення + `DevGlyph` поруч.
- Короткий `docs/design-system.md`: принципи («IDE, а не казино»), токени, коли який компонент,
  do/don't зі скріншотами.

## Прогрес

**2026-10-25 — етап 1 (токени) зроблено**, гілка `task/T-004-stage1-tokens`.
- `shared/theme/tokens.ts`: сира `palette` + семантичні `colors.surface.{base,raised,overlay,sunken,inset}`,
  `colors.text.{primary,secondary,muted,onAccent}`, `colors.border.*`, `colors.feedback.{success,warning,danger}`
  (+`*Bg`), `colors.focus`. `text.muted` піднято до `#7d8987` (було 3.6–4.1:1 на поверхнях, тепер ≥ 4.5:1).
- `resources.{capital,cognitive,influence,stress,flow}` → `{ color, bg, glyph, labelKey }`. Influence тепер
  має гліф `trend` (↗), Flow лишився `bolt` — HUD читає гліфи й кольори з токенів.
- Аліаси `green/indigo/rose/gold` (і `amberLight/redLight`) видалено; споживачі (`Badge`, `GameButton`,
  `ProgressBar`, `ResourcePill`) переведено на семантичні токени.
- Типографіка: `MIN_READABLE_FONT_SIZE = 11`, ролі `typography.roles.{display,title,body,label,monoNum}`
  (`monoNum`/`display` — `tabular-nums`). У `shared/ui` магічних 8/9 px більше немає.
- Тема = об'єкт: `baseTheme`, `applyAccentOverlay`, `createRankTheme(rank)`; `getRankTheme` тепер похідна від
  `RANK_ACCENT_OVERLAYS` (форма для віджетів не змінилась). Готово до `ThemeProvider` (E15).
- `contrastRatio` (WCAG, чиста функція на hex) + тести: text/surface ≥ 4.5:1 (вкл. відтінки рангів),
  `onAccent` на заливках, кольори ресурсів/feedback як текст.
- `GameButton primary`: білий на фіолетовому (2.9:1) → `text.onAccent` (6.7:1) для всіх заливних тонів;
  `sm` тепер теж 44 pt.

**Тимчасово лишено (deprecated, приберемо в етапі 2 разом із перевіркою віджетів):**
- `colors.bg.*` (= `surface.*`), `colors.text.inverse` (= `onAccent`), `theme` (= `baseTheme`) — щоб не
  чіпати верстку віджетів, які паралельно переробляє T-002.
- `typography.sizes.xxs` тепер = 11 (було 9): віджети, що його використовують, стали трохи більшими —
  перевірити на 375×812 разом з T-002. Магічні 8/9/10 у віджетах лишились (етап 2 / grep-тест).
