# T-027 · Мовні дрібниці uk

## Навіщо (людською мовою)
Хвости з T-005: «Бракує 250 Когнітивка» замість «Когнітивки», і десь «Тапай», а десь «Тапни». Дрібниця,
але гравець бачить це щохвилини і відчуває «машинний переклад».

## Що зробити
1. Шаблони з назвою ресурсу в непрямому відмінку: окремі ключі форм ресурсу (`resources.<id>.genitive`
   тощо) або переформулювання шаблону так, щоб відмінок не потрібен («Бракує: 250 ◈ Когнітивка»).
   Для числівників — правильні форми множини (1 / 2–4 / 5+), якщо i18n-шар це підтримує або додати мінімальну підтримку.
2. Одна форма наказового способу в uk для тапу (узгодити: «Тапни» для одноразової дії, «Тапай» для
   тривалої — або одна форма скрізь) і записати правило в `docs/design-system.md`.
3. Тест: шаблони не підставляють назву ресурсу туди, де потрібен непрямий відмінок (за списком ключів).

## Критерії готовності
- [ ] Усі «Бракує …» та подібні шаблони граматично правильні в uk.
- [ ] Одна узгоджена форма наказу; правило задокументоване.
- [ ] `npm run ts:check`, `npm test` (включно з `localeParity.test.ts`), web export пройшли.

## Де в коді
`src/shared/i18n/locales/*.json`, віджети, що збирають рядки з назвою ресурсу.
