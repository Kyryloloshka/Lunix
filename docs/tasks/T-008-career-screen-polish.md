# T-008 · Кар'єра відчувається як шлях, а не як список заборон

## Навіщо (людською мовою)
Промоушн — головна мета мезо-циклу, але зараз екран «Грейди» — це 8 червоних плашок «ЗАБЛОКОВАНО»
і одна вимога. Червоний = «помилка», а не «попереду цікаве». Кнопка «Підвищитись» з'являється
лише коли всі умови виконані, тож гравець не бачить, чого саме бракує, а сам промоушн проходить без
жодного свята — найбільший момент гри відчувається як зміна тексту в HUD.

## Що бачимо зараз
- Майбутні ранги — `Badge tone="danger"` «ЗАБЛОКОВАНО» (`CareerRoadmap.tsx:106-109`), прозорість 0.5.
- Для Influence немає прогрес-бару, тільки текст «0 ⚡ / 5 ⚡».
- Кнопка промоушну рендериться лише при виконаних умовах; немає `accessibilityLabel`.
- Ранг дублюється: HUD «[1] Самоучка» і герой-блок «СЕСІЯ / КАР'ЄРА_001 // САМОУЧКА» + опис на
  **кожній** вкладці (~50 pt висоти). Рядок «СЕСІЯ / КАР'ЄРА_001» додатково повторюється в клікері.
- Назви рангів: «Самоучка» українською, далі «Trainee Engineer», «Junior Developer» англійською
  (можливо, свідомо — IT-сленг; вирішити разом з T-005).

## Що зробити
0. **Драбина вгору, майбутнє приховане** (рішення користувача, 2026-10-24):
   - Список іде **знизу вгору**: пройдені ранги внизу, поточний над ними, наступний — над поточним.
     Кар'єра «росте вгору», як драбина. Екран відкривається проскроленим до поточного + наступного рангу.
   - Повністю видно лише пройдені, поточний і **наступний** ранг (назва, опис, вимоги).
   - Над наступним рангом — **один** силует «???» без номера, назви і вимог (цікавість, Зейгарнік).
     Скільки рангів попереду — не показуємо.
   - **Масштаб прихований повністю** (уточнення користувача, 2026-10-24): ні лічильника «3 з 9», ні
     фіналу «CEO». Фінал відкривається лише тоді, коли стає наступним рангом. Прибрати бейдж
     `career.progressBadge` і «[N]» перед назвою рангу в HUD.
   - Коли ранг відкривається, силует «знімає маску» анімацією (T-015).
   - Видимість (`visible | next | hidden`) рахує чиста функція в моделі `career-rank`.
1. Наступний ранг — акцентний «Наступна ціль». Без червоного; стан передається текстом, не тільки кольором.
2. Блок вимог: `Meter` на кожну умову наступного рангу з числами (набір умов і ресурсів задає
   T-016 — фаза навчання має умови по Cognitive і хард-скілах, а не по Capital). Кнопка «Підвищитись»
   видима завжди, неактивна з причиною («бракує 3 впливу»).
3. **Свято промоушну:** повноекранний момент на 1.5–2 с — новий титул, що змінилось (новий акцент
   теми, відкриті скіли), хаптика heavy, звук (якщо T-006 b). З reduced motion — статична картка.
   Подія `rank_up` з моделі, UI підписується (PRD §7).
4. Прибрати герой-блок з усіх вкладок, крім «Консолі» (або взагалі — HUD уже показує ранг); прибрати
   дубль «СЕСІЯ / КАР'ЄРА_001» з клікера.
## Критерії готовності
- [ ] Драбина йде знизу вгору; відкривається на поточному/наступному ранзі.
- [ ] Видно лише пройдені, поточний, наступний ранг і один силует; ні загальної кількості, ні фіналу
  наперед; тест на модель видимості (включно з ситуацією «наступний — фінал»).
- [ ] На екрані кар'єри немає червоного для звичайних майбутніх рангів.
- [ ] Гравець бачить прогрес по обох умовах і чого бракує, кнопка має a11y-лейбл і disabled-стан.
- [ ] Промоушн показує святкову картку; з reduced motion — без анімацій.
- [ ] Герой-блок не з'їдає місце на «Стек»/«Топ»/«Опції».
- [ ] ts:check, test, web export пройшли.
