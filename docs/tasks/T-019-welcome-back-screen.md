# T-019 · Повернувся — бачиш, що заробив

## Навіщо (людською мовою)
Гравець закриває гру на ніч, вранці відкриває — і баланс просто трохи більший. Офлайн-дохід уже
нараховується (до 8 год, один раз), але гравець цього не помічає. Гачок «офлайн-сюрприз» з PRD §4
працює лише тоді, коли повернення — подія: «Поки тебе не було, ти вивчив 3 мови і закрив 42 тікети».

## Що бачимо зараз
- `applyOfflineProgress` у `src/entities/currency/model/currencyStore.ts` повертає зароблене, а
  `src/application/persistence/useGamePersistence.ts` тихо його застосовує. UI немає.
- `MAX_OFFLINE_SECONDS = 8 год`, `OFFLINE_EFFICIENCY = 1` (100% пасиву, без Flow і стресу).
- Стрес за час відсутності не спадає явно (перевірити — гравець має повертатись відпочилим).

## Що зробити
1. Модель: результат офлайну як дані `{ seconds, capped, earned: { capital, cognitive, influence } }`,
   повертається з одного місця і застосовується рівно один раз (safe-code §2). Сейв одразу після.
2. Екран/модалка «Поки тебе не було» (новий віджет): скільки часу минуло, що заробив по кожному
   відкритому ресурсу (`ResourceValue`), жартівливий рядок-«звіт» за фазою (навчання: «прочитав 12
   документацій», робота: «закрив N тікетів») з i18n uk/en/es, кнопка «Забрати».
3. Показувати лише якщо відсутність ≥ 60 с і є що показати; кап («сховище повне, 8 год») — окремим
   рядком, без докору (гачок «м'яка втрата», не покарання).
4. Стрес за відсутність — до 0 (відпочив). Якщо змінює правила — задокументувати в PRD §5.
5. Анімація count-up через motion-примітиви T-015, reduced motion — без руху.
6. **Спільна черга модалок** (ця задача — власник, див. карту перетинів): одна модель «що показати
   наступним» для офлайн-екрана, свята промоушну (T-008), картки відкриття ресурсу (T-016), далі — інциденту
   (T-024) і престижу (T-026). Модалки ніколи не накладаються; перевести наявні на чергу.

## Критерії готовності
- [ ] Після закриття на ≥ 60 с і відкриття гравець бачить екран з точними сумами, які збігаються з
      приростом балансу (тест моделі).
- [ ] Повторне відкриття / hydrate не нараховує вдруге (регресійний тест).
- [ ] Годинник назад → 0, немає таймстемпу → 0, екран не показується.
- [ ] Тексти uk/en/es, проходять `parodyContent.test.ts` і `localeParity.test.ts`.
- [ ] `npm run ts:check`, `npm test`, web export пройшли.
