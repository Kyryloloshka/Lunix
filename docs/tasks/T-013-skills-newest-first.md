# T-013 · Свіже і найсильніше — першим

## Навіщо (людською мовою)
Зараз список іде від найдешевшої навички (CSS) до найдорожчої. Через годину гри найважливіша покупка,
тобто щойно відкрита і найприбутковіша навичка, опиняється внизу, і до неї треба скролити. Старі
навички, які вже майже не дають приросту, займають перший екран. Перевертаємо: новий тир зверху,
«пройдені» навички опускаються вниз. Щойно відкрита навичка — найсильніший момент цікавості, і її
треба підсвітити.

## Що зробити
1. Порядок у кожній категорії — від вищого тиру до нижчого (за `unlockRank`, потім за `baseCost`,
   обидва за спаданням). Порядок **стабільний**: не сортувати за «що можу купити», бо список
   стрибатиме під пальцем.
2. Бейдж «NEW» на навичці, відкритій з моменту останнього перегляду вкладки. Знімається після
   першого перегляду або покупки. «Бачені» id зберігаються в сейві: міграція + тест.
3. Анімація появи нової навички зверху: slide-in + підсвітка (з T-015; з reduced motion — без руху).
4. Над списком — «тизер» наступної закритої навички: силует «??? · відкривається на ранзі Junior».
   Назву не показуємо (цікавість), умову — показуємо.
5. Те саме правило для апгрейдів: доступні й не куплені зверху, куплені вниз, «ще не по рівню» — під
   доступними.
6. Логіка сортування — чиста функція в моделі з тестами, віджет лише рендерить.
