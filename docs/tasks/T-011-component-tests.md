# T-011 · UI-регресії ловить CI, а не гравець

## Навіщо (людською мовою)
Усі тести зараз — про модель. Регресії з цього ревʼю (обрізані заголовки, хардкод-тексти, кнопки без
лейблів, перемикач без ефекту) жоден тест не зловив би. Кілька компонентних тестів на головні флоу
дешевші за ручний обхід перед кожним релізом.

## Що зробити
1. Додати `@testing-library/react-native` (після погодження, `npx expo install`).
2. Тести флоу: тап по клікеру збільшує Capital; купівля скіла списує точну суму і піднімає рівень;
   кнопка неактивна, коли не вистачає; промоушн доступний лише при виконаних умовах;
   перемикання вкладок.
3. Тести доступності: кожен `Pressable` має `accessibilityRole` і лейбл; вкладки мають `selected`.
4. Тест «перемикання мови змінює тексти на кожній вкладці» (страхує T-005).
5. Без снепшотів як єдиного покриття.

## Критерії готовності
- [ ] ≥ 6 компонентних тестів, усі в `__tests__/` відповідних слайсів.
- [ ] Тест a11y падає, якщо додати кнопку без лейбла.
- [ ] `npm test` у межах розумного часу (< 60 с локально).

## Де в коді
`widgets/*/__tests__`, `pages/game-screen/__tests__`, `jest.config.js`.
