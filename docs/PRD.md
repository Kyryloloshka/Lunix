# Lunix — PRD: клікер для розробника

Статус: затверджено 2026-10-24. Робоча копія для обговорення: https://claude.ai/artifact/KRJVJv8wQkUHLUHF9gtfY1
Стислі обов'язкові правила, що випливають з цього документа: [`.agents/rules/product.md`](../.agents/rules/product.md).

## 1. Огляд продукту

**Dev Clicker: Junior → CEO (Lunix)** — мобільний incremental/idle-клікер, де гравець проходить кар'єру
розробника від студента-самоучки до CEO техгіганта, а потім «перезапускає» кар'єру в новому стартапі з
постійними бонусами. Ціль — D30 retention ≥ 12% і середня сесія ≥ 8 хв за рахунок гачків Cookie Clicker,
Egg Inc і Evolution-подібних мерджів.

**Бачення.** «Cookie Clicker, який розуміє айтішника»: кожен апгрейд — впізнаваний мем або технологія
(Tailwind JIT, V8 Turbofan, Kubernetes), кожен інцидент — «прод упав у п'ятницю». Гумор і впізнаваність —
головний диференціатор на переповненому ринку idle-ігор.

| Сегмент | Хто | Що тримає |
| --- | --- | --- |
| Core | Розробники, QA, DevOps 20–35 років | Меми, впізнаваність стеку, оптимізація білдів |
| Adjacent | Студенти IT-курсів, джуни | Фантазія кар'єрного росту, мотивація |
| Broad | Фанати idle-ігор | Великі числа, престижі, офлайн-прибуток |

**North Star:** щоденні активні гравці, що зробили ≥ 1 промоушн або престиж за тиждень.

| Метрика | Ціль MVP | Ціль 1.0 |
| --- | --- | --- |
| D1 retention | 40% | 45% |
| D7 retention | 15% | 20% |
| D30 retention | 6% | 12% |
| Сесій на день | 4 | 6 |
| Середня сесія | 5 хв | 8 хв |
| Час до першого престижу | 2–3 год | 2–3 год |
| Конверсія в оплату | — | 2–4% |

**Не-цілі першого релізу:** реальний онлайн-лідерборд, PvP, акаунти й бекенд (first release local-only).

## 2. Поточний стан проєкту

Стек: Expo SDK 58, React Native 0.88, React 19.3, TypeScript 6, Zustand 5, Reanimated 4.7,
react-native-svg, expo-haptics, expo-av, AsyncStorage, Jest 30. Архітектура — Feature-Sliced Design.

| Область | Що є | Стан |
| --- | --- | --- |
| Ресурси | Capital, Cognitive, Influence + Stress 0–100 (`entities/currency`) | Готово |
| Великі числа | Власний `Decimal` (mantissa/exponent) + форматування з нотаціями | Готово, з тестами |
| Клік | Тап, крит 8% ×2, комбо 12 тапів за 4 с → Flow ×3 на 10 с | Готово |
| Стрес | +0,35 за тап, −0,25/с; вище 70 — вихід до −50% | Готово, без активного вибору гравця |
| Скіли | 11 скілів (hard/soft), експонента 1,15–1,20, пререквізити, bulk-покупка | Готово, контенту мало |
| Тех-апгрейди | 6 множників ×2–×3 на скіл | Готово, контенту мало |
| Кар'єра | 9 рангів (Студент → CEO), гейти по Capital + Influence; погоджено перехід на 11 рангів у 3 фазах (`docs/economy/phases.md`, T-016) | Частково: немає співбесід |
| Лідерборд | Симульовані NPC, чесно позначені | Частково: статичний список |
| Налаштування | Звук, вібро, reduced motion, нотація, мова (uk/en/es) | Готово |
| Збереження | Сейв v1 в AsyncStorage, валідація, AppState (`src/application/persistence`) | Базово: один слот, без міграцій |
| Офлайн-прибуток | Кап 8 год, ефективність 100%, одноразове нарахування | Базово: без екрана повернення і апгрейдів капу |
| Престиж, досягнення, інциденти, квести | — | Відсутнє |

Технічні борги, що заважають масштабуванню:
- Стан прогресу розкиданий по кількох Zustand-сторах; транзакції між ними не атомарні.
- Ефекти скілів — окремі поля (`capitalPerLevel`, `clickCapitalPerLevel`…), а не універсальна система.
- `Math.random()` у критах — недетерміновано, складно тестувати баланс.
- Частина контенту захардкоджена текстом у TS, а не в i18n-ключах.

## 3. Ринок і конкуренти

Idle-жанр зрілий і перенасичений генеричними тайкунами, але ніша «клікер для розробників» практично
порожня. Шанс Lunix — поєднати мету рівня Cookie Clicker / Antimatter Dimensions з віральним айті-гумором.
Ринкові характеристики жанру наближені (з пам'яті, не перевірені свіжими джерелами): високий D30 серед
кажуал-жанрів, дохід на rewarded video + IAP, топові проєкти живуть роками на LiveOps.

| Гра | Сильна сторона | Що беремо в Lunix |
| --- | --- | --- |
| Cookie Clicker | Глибока мета, секрети, гумор | Golden Cookie → «Golden Commit», Heavenly Chips → «Equity», сотні досягнень, shadow-ачівки |
| Adventure Capitalist | Простий луп «бізнес + менеджер» | Менеджери = найняті джуни, що автоматизують скіл; пороги рівнів 25/50/100 |
| Egg, Inc. | Економіка мобільного idle, контракти | Контракти = «фріланс-проєкти» з дедлайном; артефакти; престиж |
| Cell to Singularity / Evolution | Мердж і еволюція, дерево відкриттів | Дерево технологій від Assembler до AGI; мердж артефактів коду |
| Antimatter Dimensions | Шари престижу, челенджі, автоматизація | 3 шари престижу, челендж-рани, автобаєри як нагорода |
| Idle Miner Tycoon | Менеджери з активками, монетизація | Менеджери з рідкістю та активними скілами, події з окремою валютою |
| Melvor Idle | RPG-глибина в idle, одноразова покупка | Mastery-рівні навичок, преміум без агресивної реклами |
| Universal Paperclips | Наративні фази, що змінюють гру | Ранг змінює механіку: код → команда → компанія → ринок |

**Позиціонування.** Єдиний idle з реалістичною айті-кар'єрою, де кожен ранг відкриває новий шар гри, а
контент перегукується з реальним світом (релізи фреймворків, Hacktoberfest, Black Friday деплоїв).

Етичні обмеження (обов'язкові):

- NPC ніколи не видаються за реальних гравців.
- Пуші — не частіше 2 на день, з тихими годинами та легким вимкненням.

## 5. Core loop, мета-прогресія та економіка

Три вкладені петлі:
- **Мікро (секунди):** тап / крит → комбо → Flow ×3 → Golden Commit → тап.
- **Мезо (хвилини–години):** навчання → перша робота → вплив; навички й апгрейди ×N → промоушн.
- **Макро (дні–тижні):** Exit / IPO → Equity → новий ран швидше → нова ера.

Мікро дає бусти доходу мезо-петлі; ранг CEO відкриває Exit. Нова ера додає механіку, тому макро-петля не
стає повторенням.

**Фази кар'єри** (деталі, ранги, навички і ціни — [`docs/economy/phases.md`](economy/phases.md), погоджено
2026-10-24). Гравець проживає шлях розробника, ресурси відкриваються по черзі і до відкриття не видні:
1. **Навчання** (Першокурсник → Кандидат на стажування): лише Знання.
2. **Перша робота** (Trainee → Middle): з'являються гроші, спершу копійки; робота відкривається рівнями знань.
3. **Вплив** (з Middle): з'являється Influence; підвищення Senior+ його списують.

Правила: **одна навичка — один ефект** (виробляє один ресурс або є перком); окремий режим тапу на кожен
відкритий ресурс («Вчитись / Працювати / Нетворкінг»); кар'єра прихована — гравець бачить лише пройдені,
поточний і наступний ранг.

| Ресурс | Роль | Джерело | Витрата |
| --- | --- | --- | --- |
| Cognitive (Знання) | Перша валюта; пасивно — стійкість до стресу від заробленого | Тап «Вчитись», навички Знань | Навички Знань, перки, тех-апгрейди Знань і Роботи |
| Capital ($) | Основна валюта, відкривається з першою роботою (Trainee) | Тап «Працювати», навички Роботи, контракти | Навички Роботи і Впливу, перки, найм |
| Influence (Репутація) | Валюта кар'єри, відкривається на Middle | Тап «Нетворкінг», навички Впливу | Підвищення Senior+, лідерські перки, апгрейди Впливу, найм сильних NPC |
| Stress (0–100) | Ризик-метр, не валюта | Тапи, інциденти, дедлайни | Відпочинок, кава, відпустка |
| Equity (нове) | Престиж-валюта, +2% до всього за одиницю | Exit / IPO | Perks дерева престижу |
| GitHub Stars (нове) | М'яка преміум-валюта | Ачівки, дейлі, реклама, IAP | Тайм-скіпи, косметика |

**Стрес як активний вибір.** Вище 70 — штраф до −50%. Додаємо «Crunch Mode»: при стресі ≥ 80 гравець може
свідомо увімкнути ×5 на 30 с з ризиком Burnout (5 хв без тапів).

Формули:

```text
cost(n)  = base · r^n                     (r = 1,15–1,20)
income   = lvl · perLvl · 2^milestones · ∏upgrades · ∏leadershipPerks · (1 + 0.02·Equity) · (1 + 0.01·achievements)
           milestones — пороги рівня 25/50/100/200, кожен ×2
tap      = base(mode) · ∏tapPerks + 5% · passivePerSec(resource of mode)
Equity   = floor( sqrt(totalCapitalEarned / 1e12) )
```

Балансні цілі: перша покупка ≤ 10 с; наступна ціль завжди ≤ 60–90 с в активній грі; Trainee (перша
зарплата) — 4–5 хв, Junior — ~10 хв, Senior — ~1 год, CEO — 2–3 год першого рану. Перевіряється
симулятором (E8; прототип — `docs/economy/phasesim.js`).

- E8: CI запускає симуляцію повного рану й падає, якщо час до рангу виходить за ±20% цілі.

## 7. Архітектура

Залишаємо FSD, але вся гра — в одному чистому рушії `entities/game-core` з єдиним `GameState` і набором
систем. Контент — дані з універсальними ефектами: новий скіл, ачівка чи інцидент додається без змін коду.

Шари (стрілки тільки вниз): **UI** (pages/widgets, лише рендер і селектори) → **Features** (use cases,
`dispatch(action)`) → **Game Engine** (системи Production, Economy, Events, Progression, Prestige, Meta;
детермінований tick) → **Content registries** + **Infrastructure** (Decimal, SaveRepository, RNG, Clock,
EventBus, порти Analytics / Ads / IAP).

Принципи:
1. **Одне джерело правди.** Один стор `useGame` з `GameState`; слайси — поля, транзакції атомарні.
2. **Редьюсери + системи.** `reduce(state, action)` для дій гравця; `tick(state, dt, ctx)` — пайплайн систем у фіксованому порядку; `ctx` містить `rng` і `now`.
3. **Похідне не зберігаємо.** Rates і множники — мемоізований селектор `computeModifiers(state, content)`.
4. **Універсальні ефекти.** `Effect { target, op: add | mul | pow, value, scope }` — для скілів, апгрейдів, ачівок, Perks, бафів, івентів.
5. **Умови як дані.** `Condition` (`skillLevel`, `rank`, `totalEarned`, `stat`, `and/or/not`) — анлоки, ачівки, квести, тригери інцидентів.
6. **Порти і адаптери.** `SaveRepository`, `Analytics`, `Ads`, `IAP`, `Notifications`, `Clock` — інтерфейси в `shared`, реалізації в `app`, фейки в тестах.
7. **Події рушія.** Рушій повертає `events[]` (`skill_bought`, `rank_up`, `golden_clicked`); на них підписані ачівки, аналітика, звук, хаптика.

Цільова структура:

```text
src/
  app/            # бутстрап, DI адаптерів, AppState-луп, навігація
  pages/          # game, prestige, collection, settings, event
  widgets/        # hud, clicker, skills-catalog, team, offline-modal, golden-commit
  features/       # buy-skill, buy-upgrade, prestige-exit, claim-offline, resolve-incident, hire, daily
  entities/
    game-core/    # GameState, reducer, tick pipeline, selectors, save schema + migrations
    economy/      # формули цін, bulk, Effect/Modifier engine
    content/      # реєстри: skills, upgrades, ranks, incidents, achievements, perks, quests
    events/ prestige/ progression/ meta/   # системи
  shared/
    lib/decimal  lib/rng  lib/clock  lib/event-bus
    ports/        # SaveRepository, Analytics, Ads, IAP, Notifications
    ui/ theme/ i18n/
tools/
  balance-sim/    # хедлес-симулятор рану + CSV-звіт
```

Збереження: снепшот `{ version, savedAt, state }`, Decimal як `{ m, e }`; ланцюжок міграцій з тестами;
два слоти з відкатом; автосейв 10 с і на `background`; експорт/імпорт рядком base64. MMKV замість
AsyncStorage — відкрите питання.

Масштабованість і продуктивність: рушій тікає кроком 100 мс, UI оновлює числа 4 рази/с через вузькі
селектори; анімації на UI-потоці Reanimated; офлайн рахується аналітично (`rate × dt`); контент
валідується схемою в тестах (унікальні id, посилання, i18n-ключі); реєстри згодом можуть приходити з
remote config.
